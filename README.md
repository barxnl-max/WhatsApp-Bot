# 🤖 WhatsApp Bot – Baileys Multi-Device

Powerful and modular **WhatsApp Bot** built with **Node.js (CommonJS)** and **Baileys Multi-Device**.  
Designed to be fast, stable, and easy to customize.

---

## ✨ Features

- 🤖 AI Chat (OpenAI / Gemini / Groq)
- 📥 YouTube & Media Downloader
- 🖼️ Sticker Maker (Image / Video / GIF)
- 🎵 Music Search & Download
- 👥 Group Management (anti-spam, welcome, admin tools)
- 🔎 Web Scraping & Search
- ⚡ Fast & Lightweight
- 🔐 Secure Multi-Device Session
- 🧩 Modular Command System

---

## 📦 Tech Stack

- **Node.js ≥ 20+**
- **Baileys (WhatsApp Multi-Device)**
- **CommonJS (CJS)**
- Express
- FFmpeg
- Sharp / Jimp
